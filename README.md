# 🤝 COLLABORATION & CONTRIBUTIONS

This repository is collaboratively maintained by all team members.

Each member is encouraged to:

- Document their solved challenges.
- Share investigation methodologies.
- Include relevant screenshots and supporting files.
- Explain tools and techniques used.
- Review and improve existing writeups.
- Contribute through Git branches and pull requests.

### Contribution Workflow

1. Clone the repository.
2. Create a separate branch for your contribution.
3. Add your challenge writeup.
4. Commit and push your changes.
5. Open a Pull Request for review.
6. Merge the contribution into the main branch.
